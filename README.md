# 🎡 Pointauc Offline

Локальная (офлайн) версия популярного стримерского инструмента **Pointauc**, предназначенная для проведения интерактивных аукционов, лотерей и розыгрышей с помощью колеса фортуны. Этот инструмент полностью работает на стороне клиента и не требует подключения к Twitch, DonationAlerts или другим платформам — идеально подходит для офлайн-ивентов, тестирования или локальных записей.

🌐 **Демо-версия:** [punpude.github.io/Pointauc_offline](https://punpude.github.io/Pointauc_offline/)

---

## 📋 Основные возможности

*   **🎨 Полная кастомизация**
    *   Настройка основных и фоновых цветов, прозрачности элементов, размытия и затемнения фона.
    *   Выбор пресетов стилей оформления.
    *   Анимированный звездный фон, который можно включить по желанию.

*   **⚙️ Гибкое управление аукционом**
    *   Проведение розыгрышей с помощью настраиваемого колеса фортуны.
    *   Управление списком участников: добавление, удаление, распределение шансов.
    *   Возможность импорта/экспорта лотов в текстовом формате (формат: `Название | Цена`).
    *   Настройка таймеров и длительности вращения колеса.

*   **📦 Архивация и хранение**
    *   Сохранение истории проведенных аукционов и лотов в локальном хранилище браузера (IndexedDB).
    *   Возможность полной очистки архива в один клик.

*   **🌐 Мультиязычность**
    *   Поддержка русского и английского языков интерфейса.

---

## 🛠️ Технологии

*   **Vanilla HTML/CSS/JavaScript** — без использования фреймворков.
*   **Canvas API** — для отрисовки колеса фортуны.
*   **LocalStorage / IndexedDB** — для сохранения данных и истории на стороне клиента.
*   **Google Fonts** — для шрифтов (`Inter`, `Roboto`).
